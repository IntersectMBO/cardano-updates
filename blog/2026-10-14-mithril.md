## High level overview

This week, the Mithril team completed hardening the SNARK primitives and distinguishing the canonical bytes encoding in the STM library. They kept working on resolving the SNARK verification key collisions deterministically in the key registration, publishing the immutable archives directory under an IPNS name in the aggregator, and identifying a crate for the user interaction of the setup command.

The team completed the upgrade to Cardano node `11.1.3`, adding a keypair generation tool in the aggregator CLI, and detecting the yanked crates in the CI.
They also worked on the new distribution release, the upgrade to Cardano node `11.2`, the update of the DMQ node to `0.7.2.0`, and kept investigating the blocks and transactions verification failure on the `testing-preview` network.

Finally, they fixed the WASM client tests which terminated themselves, the firewall configuration in the infrastructure which opened unused Mithril relay ports when the real DMQ node is used, and the DMQ node SRV record prefix in the signer documentation.
