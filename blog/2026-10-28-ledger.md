## High level summary

Leios remained the main focus and moved further toward its concrete block and certificate structure. We added the `LEIOSCERT` rule together with the Leios-certificate-related `BBODY` failures, defined the `EbReferences` CDDL and an `Annotator` decoder for it, and started tracking the last tick slot number in the new epoch state and the last endorser block announcement in the ledger state. We also prevented duplicate BLS keys from being used, improved how Leios committee seats are rendered (hex keys and decimal weights), integrated the week 42 ledger changes on the prototype branch, and backed the work with Leios certificate golden tests and better example parameters.

A significant milestone was the Dijkstra era gaining its economic machinery: we implemented the `minFee` calculation for Dijkstra, adopted the CIP-23 effective cost and margin in the rewards calculations, and fixed the block body size computation. There was also a cluster of serialisation and decoder fixes, covering the `PlutusData` decoder, redeemers for protocol version 12, `NonEmpty` set and map decoders, and the IPv4 encoding order (now network order rather than swapped), with property tests added for Plutus data conversion.

Work on sub-transactions continued, with min-ada validation switched to a non-static check and `submitTx` in the ImpTests now randomly exercising top-level and sub-level transactions, alongside new Imp tests for `SUBDELEG`, `SUBPOOL` and `SUBGOVCERT`. On the rules side we added `LEDGER` rule limits and stopped inverting predicate failures in the small-steps framework, and we simplified transaction hashing by removing `hashTx` and the `DijkstraEraTx` type class in favour of the existing `HashAnnotated`. We also added a `queryStakePoolState` ledger state query.

On the testing and releasing side we enabled ExUnits tests and fixed the bootstrap witness in conformance, made the Plutus tests run with arbitrary Plutus versions, added tests for `transValidityInterval` and for the `ValidityInterval`/`VotingProcedures` semigroup and monoid instances, tested voting stake computation for pools with zero delegations, updated the formal ledger specification, and filled in a few missing predicate-check ImpTests. Infrastructure changes were limited to a `cleret` bump to 0.5.2.1 and a dependency update.
