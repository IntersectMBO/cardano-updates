## High level summary

We continued with Leios work this cycle, with most of the work going into the endorser block and the block header. The endorser block rule gained its real validations, moving it past the placeholder check it started out with. The Leios header hash was corrected so that it covers only the header body and the KES signature.
Forecasting was extended with the maximum transaction size, which Leios is the first protocol to have a reason to forecast, and the block header coders were brought back.

CIP-172, self-usable transaction outputs, was implemented, reaching across the Babbage, Conway and Dijkstra eras.

Two protocol-level safety fixes landed. Governance updates that would set the maximum pledge leverage below one are now rejected, since such a value can produce negative pool rewards and abort reward application entirely. Separately, a change to the VRF duplicate counter that had accidentally altered Conway behavior while fixing Dijkstra was reverted, the two code paths having turned out not to be equivalent.

Sub-transaction support was rounded out on the API side. The helper reporting the outputs a transaction produces now includes sub-transaction outputs, where a batch creating three UTxOs previously reported only the top-level one. The timelock upgrade function was also fixed and renamed.

Testing was dominated by Plutus V4 and by conformance. The V4 transaction info translation, which had been merged without unit tests, received a thorough set covering each translated field. The Plutus script decoder is now checked to agree with the Plutus deserializer across every language, PLC version, protocol version and builtin. A transaction-level guard script exercises batch validation, including the phase-2-invalid cases. The formal ledger specification was updated three times over the cycle, each time enabling further tests, and the maximum pool stake calculation is now property-tested against the specification.

Tooling gained a custom git diff driver for CBOR files, wired up automatically through the development shell, so binary CBOR now shows up as readable text in diffs.
